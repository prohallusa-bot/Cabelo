Implementation notes

  • Render pipeline: this exact HTML, rendered server-side to PNG at 1080×1920 (9:16 story) via headless Chrome or satori. Also export 1080×1350 (4:5 feed) — same template, photos area grows, spacer shrinks.
  • Template variables: {before_photo} / {after_photo} / {day1_photo} (signed URLs from check-in storage), score values, delta, protocol name + week, stylist name + city, referral code.
  • Score ring math: circumference 251.3 (r=40). dashoffset = 251.3 × (1 − score/100).
  • Referral code: generated per user via Shopify discount API (same service as stylist commission codes). QR deep-links to cabelo.ai/s/{share_id} → public score page → analysis funnel with code pre-applied.
  • Share page = GEO asset: the landing page behind the QR is public and crawlable (score, anonymized result summary, stylist credit) — every share feeds the public layer.
  • Variant logic: delta ≥ +8 at any check-in → offer Variant A. First analysis → offer Variant B. Never auto-post; always explicit user consent per share, and photo use requires the user's opt-in at capture time.
  • Stylist credit is load-bearing: it's the citation-authority loop made visible — keep it on every card where a stylist prescribed the protocol.
  • Fonts: Playfair Display (600) headings, Inter body — Google Fonts, both free for commercial use.
  • Localization: all strings through the existing locales/ JSON (EN/PT/ES). Playfair + Inter cover Latin Extended for Portuguese diacritics.
